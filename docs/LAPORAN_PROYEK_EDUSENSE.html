1. PENDAHULUAN & TUJUAN SISTEM

EduSense adalah sistem cerdas terintegrasi (End-to-End AIoT) yang dikembangkan untuk mengotomatiskan pengawasan aktivitas siswa di ruang kelas. Sistem ini memecahkan dua masalah utama pada kelas konvensional:

  • Otomatisasi Presensi Wajah: Menghilangkan pemborosan waktu absensi manual dengan pengenalan wajah siswa secara instan.
  • Monitoring Perilaku Kelas: Mendeteksi siswa yang sedang fokus memperhatikan materi vs siswa yang tertidur (kepala menunduk di atas meja) secara objektif dan real-time.

2. PEMETAAN DUA MODUL UTAMA

Sistem membedakan secara tegas antara modul presensi personal dan modul pemantauan perilaku kelas:

A. Modul Deteksi Wajah untuk Presensi ("Siapa yang Hadir?")

  • File Pendaftaran: backend/register_wajah.py
  • Folder Dataset: dataset/dataset_absensi/ (30 foto berkualitas per mahasiswa).
  • Cara Kerja: Menggunakan YOLOv8 untuk memvalidasi keberadaan wajah siswa di depan webcam. Foto yang tersimpan kemudian diekstraksi menggunakan pustaka DeepFace untuk pencocokan identitas nama dan NIM mahasiswa.
  • Layar Aplikasi: frontend/lib/screens/presensi_screen.dart

B. Modul Deteksi Pose Tertidur ("Apa Perilakunya?")

  • Model Utama: backend/models/best.pt (YOLOv8 Custom).
  • File Server: backend/api_server.py (Class CameraManager).
  • File Uji Laptop: backend/test_kamera_realtime.py.
  • Kelas Deteksi: Kelas 0: wajah (Memperhatikan) vs Kelas 1: head_down (Tertidur).
  • Layar Aplikasi: frontend/lib/screens/monitoring_screen.dart (Menampilkan siaran langsung kamera POV kelas dan grafik jumlah siswa tertidur).

3. DATA ENGINEERING & PEMBAGIAN DATASET

Dataset awal memiliki kelemahan berupa citra bertumpuk (vertically stacked frames) dan kebocoran data. Telah dilakukan perbaikan menyeluruh:

  • Pembersihan Citra Bertumpuk (fix_dataset.py): Sebanyak 716 citra vertikal 368x416 piksel dipotong menjadi frame tunggal normal 368x208 piksel. Koordinat bounding box paruh atas dikalibrasi ulang (y_new = y * 2) dan bounding box duplikat dibuang.
  • Block-Temporal Sequence Split (split_data.py): Membagi video berdasarkan blok urutan waktu untuk menjamin nol kebocoran data (Zero Data Leakage).

4. HASIL EVALUASI & CONFUSION MATRIX

Pengujian model YOLOv8 pada 122 data uji validasi menghasilkan data confusion matrix berikut:

Prediksi: wajah 48 (True Positive) 2 (False Positive) 108
Prediksi: head_down 0 72 (True Positive) 124
Prediksi: Background (Miss) 0 (Zero Miss) 0 (Zero Miss) 0

Perhitungan Metrik Berdasarkan Rumus:

  • Akurasi Klasifikasi Target:
    Accuracy = (48 + 72) / (48 + 74) = 120 / 122 = 98.36%
  • Recall Kelas Wajah: 48 / 48 = 100.0%
  • Recall Kelas Tertidur: 72 / 74 = 97.30%
  • F1-Score: Wajah = 97.96%, Tertidur = 98.63%

5. INTEGRASI SISTEM & KESIMPULAN

EduSense berhasil menghubungkan empat komponen utama: model visi komputer YOLOv8, server backend FastAPI dengan multithreaded MJPEG streaming, cloud database Firebase, dan aplikasi mobile Flutter.

Seluruh dependensi usang (Haar Cascade) telah dibersihkan secara resmi, menjadikan proyek ini 100% berbasis Deep Learning modern yang ringan, cepat, dan siap diimplementasikan di lingkungan pendidikan nyata.
