SLIDE 4 • DIAGRAM ARSITEKTUR

Alur Kerja Internal Arsitektur YOLOv8s

1. Input Layer
Citra RGB diubah ke tensor:

• 640×640 saat training (train_yolo.py:59)
• 320×320 saat live CCTV (api_server.py:257)
2. Backbone (CSPDarknet)
Ekstraksi fitur spasial menggunakan blok C2f & SPPF:

Menangkap tepi wajah, tekstur rambut, dan sudut kemiringan kepala di meja.
3. Neck (PANet)
Penggabungan fitur multi-skala (Top-Down & Bottom-Up):

Mendukung deteksi siswa barisan depan (besar) & belakang (kecil).
4. Decoupled Head
Anchor-Free Head memisahkan cabang:

• Regresi BBox [x1,y1,x2,y2]
• Skor Kelas wajah / head_down
Penting untuk dijelaskan ke dosen: Pada YOLOv8 (framework Ultralytics), struktur 129 layer tersebut tidak ditulis dalam file .cfg terpisah seperti YOLOv3/v4, melainkan didefinisikan oleh library ultralytics dan tersimpan otomatis di dalam backend/models/best.pt.

Augmentasi agar model tahan variasi cahaya & jarak kelas:

hsv_v: 0.4      # Kecerahan +/- 40%

scale: 0.5      # Zoom in/out 50%
fliplr: 0.5     # Flip horizontal 50%
mosaic: 1.0     # Gabung 4 frame kelas
erasing: 0.2    # Simulasi oklusi meja/tangan
optimizer: AdamW
SLIDE 6 • INISIALISASI TRAINING

Kode Training Arsitektur YOLOv8s

📄 Letak file: training/train_yolo.py (Baris 48–71)

# Baris 48: Memuat arsitektur dasar Pre-trained YOLOv8 Small
model = YOLO("yolov8s.pt")

# Baris 55: Melatih bobot arsitektur menggunakan dataset EduSense
results = model.train(
    data=DATASET_YAML,       # Mengarah ke dataset/dataset.yaml (nc: 2)
    epochs=40,               # Putaran pelatihan optimal
    patience=10,             # Early stopping jika mAP stagnan
    imgsz=640,               # Resolusi input arsitektur saat training
    batch=16,                # Jumlah citra per iterasi
    optimizer="AdamW",       # Optimizer stabilisasi bobot
    lr0=0.001, lrf=0.01      # Penjadwalan learning rate
)
Hasil Output Training: Bobot terbaik otomatis disimpan sebagai best.pt, lalu ditempatkan di backend/models/best.pt untuk dipakai oleh server FastAPI.
